# mrjohnkenly

Personal portfolio for John Kenly.

## Deployment

The site is published with GitHub Pages from the `main` branch using the
workflow in `.github/workflows/pages.yml`. The repository root redirects to
`html/`, where the portfolio page loads its CSS, JavaScript, images, and resume
from the repository.

Push changes to `main` to trigger a deployment. The published site is available
at <https://kati-john-kenly.github.io/mrjohnkenly/>.
